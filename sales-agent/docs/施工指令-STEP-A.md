## 二、★ 核心架构约束（评审点名，违反即返工）

### 1. 分页 / 排序 / 筛选 / 聚合 / 导出 —— **全部由后端确定性计算**
前端只做：`用户操作 → 请求参数 → 展示结果`。
**禁止**：后端一次返回全部行 → 浏览器 JS 排序 → 浏览器分页。
**理由**：前端排序会形成**第二套计算路径**，将来 `HTTP API = A` 与 `CDP 页面 = B` 会出现 `A ≠ B`，破坏"确定性"这条项目铁律。

建议的接口形态（示例）：
```
GET /api/dataset/customers?page=1&page_size=50&sort=sales_amount&order=desc&start=2011-11-01&end=2011-11-30
→ { "items": [...], "page": 1, "page_size": 50, "total": 4372,
    "sort": "sales_amount", "order": "desc", "scope": { ... } }
```
（页面与导出走**同一个**查询条件 + **同一个** Repository/Executor）

### 2. 导出必须与页面**同源**
- 同一个查询条件 → 同一个 Repository / Executor → 页面分页结果 + 导出完整结果
- **禁止**：前端把当前 50 行拼成 Excel（那会产生两套业务逻辑）
- 导出格式：**xlsx（带格式）+ csv**

### 3. 原始数据不许默认全塞
- 第一层：**业务明细**（客户表 / 产品表 / 销售汇总表）
- 第二层：**原始数据浏览器**（独立入口）：分页 / 筛选 / 排序 / 搜索 / 导出，**默认只显示 50 / 100 / 200 行**
- **禁止**首次加载 541,909 行

### 4. 销售表不要固定三维
不要做成 `daily_sales / weekly_sales / country_sales` 一堆重复页面。做成：
```
维度：日 / 周 / Country
指标：销售额 / 订单数 / 客户数 / 客单价
```
同一张表，切换维度/指标 → 真实 HTTP 数据变化。

### 5. `/api/upload` 不许升级成"万能上传"
```
文档输入 Document  → Word / PDF / PPT
数据集输入 Dataset → Excel / CSV / 结构化表格
```
两者可共用底层文件存储，但**业务语义分开**，不要都塞进 `/api/upload`。

### 6. 导入的表格必须成为新的 **Dataset**
```
dataset_id / source_file / file_hash / schema / imported_at /
date_range / row_count / columns / currency / metric_definition / source_version
```
**★ 如果后端尚未支持 xlsx → Dataset 等能力：不要假装"导入成功"**
→ 先完成**前端工作流 + API Contract + 空状态/错误状态**，真实后端后续 TASK 接。

### 7. D16 口径要**绑定 Dataset**，不是全局规则
`Dataset → metric_definition（sales_amount / order_count / customer_count / return_definition）`
`Analysis Result → dataset_id`
→ 换数据源后系统能回答"这个数字基于哪个数据集、哪套口径"

### 8. 哈希保留但不进前端（对应 `docs/前端展示规范.md`）
```
后台保留：file_hash / schema_hash / dataset_version / created_at / source_file_id
前端只显示：「销售数据 · 2026-09-24 更新」这类业务语言
```
**三层信息模型**：
- 业务层（用户看）：销售额 / 客户 / 产品 / 订单 / 趋势 / 报表
- 管理层（管理员看）：数据源 / 更新时间 / 导入状态 / 数据范围 / 字段映射
- 审计层（后台存）：hash / dataset_id / schema / 版本 / 请求记录 / 操作者 / 执行记录
- **业务页面不显示**：`/api/xxx` · `TASK-00x` · `D16-6` · `sha256` · `pytest` · `Repository` · `Executor` · `loading 三态`
