## 本次任务：写测试集 `tests/test_cases.json`

**只需要这一个文件**（不要顺手写别的代码）。

### 要求

1. **50 条用例**，分三类（按 `docs/requirements.md` 第 8 节）：
   - `normal`（正常需求）**16 条**：给样本型（"照这个做上周的"）、大白话型（"做个每周销售汇总"）、混合型（"像这个，但加个环比"）
   - `edge`（边界情况）**16 条**：空数据、字段改名、时间范围特殊（跨年/只有 3 天数据）、多指标组合、含退货/取消单、CustomerID 为空
   - `needs_clarification`（需人工确认）**18 条**：找不到对应表/字段、口径歧义（"销售"含不含退货？）、需求含糊（"做个报表"没说维度）→ **期望行为是 AI 提问，而不是瞎猜**

2. **每条用例字段**（JSON）：
```json
{
  "id": "n01",
  "type": "normal",
  "user_input": "做个上周的销售汇总",
  "reference": null,            // 或 {"kind":"excel","path":"templates/sample_weekly.xlsx"}
  "expected": {
    "metrics": ["销售额", "订单数"],
    "time_range": "上周（周一~周日）",
    "data_source": "Online Retail / MySQL 映射",
    "output": "excel",
    "must_ask": false            // needs_clarification 类为 true，并在 clarify_about 说明该问什么
  },
  "notes": "大白话型，未给参考物"
}
```

3. **对齐要求**（来自工作流"数据-规则-标注三对齐"）：用例里的时间/字段必须**能对得上数据集里的真实数据**（比如"上周"要明确是哪一周，从 2010-12-06 那一周开始取，不要写数据集范围外的日期）。

4. **留出集切分**：给每条用例加 `"split": "dev"` 或 `"holdout"`，按 **8:2** 分配（40 dev / 10 holdout），**固定随机种子**（写进文件顶部 `"seed": 42`）。

5. 文件结构：
```json
{
  "seed": 42,
  "generated_for": "sales-report-agent / UCI Online Retail",
  "cases": [ ... 50 条 ... ]
}
```

### 验证方式（做完必须报告）

```
1. 条数：总 50 / normal 16 / edge 16 / needs_clarification 18
2. split 分布：dev 40 / holdout 10
3. JSON 合法（python -m json.tool 通过）
4. 贴出 3 条样例（每类各一条）
```

### 执行命令（Windows，项目根）

```bash
cd /d/sales-report-agent
.venv\Scripts\python.exe -c "import json; d=json.load(open('tests/test_cases.json',encoding='utf-8')); cs=d['cases']; from collections import Counter; print('总数',len(cs)); print(Counter(c['type'] for c in cs)); print(Counter(c['split'] for c in cs))"
```
