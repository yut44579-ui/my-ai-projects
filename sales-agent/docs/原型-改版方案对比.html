④ 数据接入：现在 vs 建议 你的建议

来源现在支持建议补齐
Excel (.xlsx)✅ 上传 + 计算多 Sheet 选择（现在只读第一个）
CSV✅ 上传 + 计算编码/分隔符自动识别
Word (.docx)⚠️ 只提取文本（表格被拉平）保留表格结构 → 可当数据源
PDF✅ 文本提取（无 OCR）表格抽取（扫描件仍如实报错）
PPT (.pptx)❌ 完全没有提取文字 + 表格（PPT 表格常是数据表）
接入后「看得见」❌ 只能被计算★ 预览前 N 行 + 字段映射 + 转成可查表格
核心差别：现在「上传 → 只给结论」；建议「上传 → 先看见表 → 再算」。 真实工作里，数据往往先在 Excel 台账、Word 报告、PPT 汇报里 —— 都得能进，而且进来要能看。

⑤ 建议的执行顺序

两步走，先解决「看不见数据」，再补「接入面」
步骤内容解决预估规模
STEP A客户/产品/销售三页出真表格（分页·排序·导出）+ 顶栏遮挡修复你的疑问 1 + 2中等
STEP BPPT 接入 + Excel 多 sheet + Word 表格保留 + 接入后预览你的疑问 3较大
