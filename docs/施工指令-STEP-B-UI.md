## 一、★ 评审的核心边界（必须遵守，越界即返工）

> 评审原话：「本轮可以做：登录页 UI / 用户头像 / 用户名 / 游客名称显示 / 在线·忙碌·离开·离线视觉状态 / 用户菜单 / 退出按钮 UI。
> **本轮不要做真实安全实现**：密码哈希认证 / Token / Refresh Token / Remember Me / Token expiry /
> 错误次数限制 / IP 冷却 / 真正 Session / 权限 RBAC / 真实操作审计 / 扫码登录 —— **全部放到 TASK-011**。」
>
> 「**不要在前端做密码哈希，然后认为已经安全。真实密码认证必须由后端完成。**」

**所以本轮：**
```
✅ 做：
  · 登录页（账号登录 + 游客入口；视觉与交互完整）
  · 用户名显示（登录时填的名字）
  · 游客名（自动「游客 + 5 位随机串」，如 游客khynx）
  · 用户头像 + 状态点 + 状态文字
  · 状态四态【视觉】：在线 / 忙碌中 / 离开 / 离线
  · 用户菜单（个人设置 / 退出登录）
  · 退出按钮 UI
  · 轻量前端会话（localStorage 记住"当前是谁"，刷新不用重登）

❌ 不做（留给 TASK-011）：
  密码哈希与校验 / Token / Refresh / Remember Me 的安全实现 / Token 过期 /
  连续错误冷却 / 真 Session / RBAC / 操作审计落库 / 扫码登录 / 第三方登录
```

**明确告知用户**：登录页要如实标注这是**本地模式的身份展示**，不是安全认证。
（用业务语言，不要写"未启用鉴权/TASK-011"这类字样 —— 见前端规范）

## 二、登录页（按原型 `docs/原型-最终版.html` 的形态）

参考的是 QQ 登录页的**结构**（非照搬）：左右分栏 + 玻璃拟态 + 「欢迎回来」+ 多种登录方式。
配色用项目既有 TDesign token。

```
左：品牌区
   · Logo（SR）+ 项目名 + 一句话定位
   · 一句价值主张（用大白话）
   · 能力标签（自然语言问答 / 销售·客户·产品 / 一键周报 / Excel·CSV 导入导出）
   · 三个可核对的数字（如 541,909 行真实数据 / 1,664 有成交客户 / 口径可追溯）
右：表单区（玻璃拟态卡片）
   · 「欢迎回来 👋」+ 副标题
   · 两个入口：账号登录 / 游客登录（**扫码登录本轮不做**，评审已砍）
   · 账号登录：姓名 + 密码（密码框带显示/隐藏）+ 记住我 + 忘记密码（占位提示即可）
   · 游客登录：本机生成随机名「游客XXXXX」，可直接进入
   · 主按钮（带 loading 态）
   · 底部：帮助 / 隐私（占位）
```

**校验（纯前端形态校验，非安全校验）**：
- 姓名 2~20 字符；密码至少 6 位（只做形态校验，**不做哈希、不做比对**）
- 校验失败：标红输入框 + 就地提示（人话）
- 提交时按钮进入 loading 态（**同时把用户状态切到「忙碌中」** —— 视觉联动）

## 三、在线状态四态（视觉层）

| 状态 | 颜色 | 触发（前端） |
|---|---|---|
| 在线 | 绿 #22C55E | 登录成功 |
| 忙碌中 | 红 #EF4444 | 提交提问/分析进行中（**与分析请求的 loading 态联动**） |
| 离开 | 橙 #F59E0B | 无操作超 N 分钟（前端计时器，建议 10 分钟） |
| 离线 | 灰 #777 | 退出登录 / 关页 |

**评审明确要求**：
> 「当前没有真实鉴权时，**它只是 UI 状态模拟/本地状态。不能宣称"用户已经真正在线"。**
>  `busy` **必须由分析任务状态驱动**，不要让前端 JS `setStatus("busy")` 就认为用户真的在忙。」

→ 落地方式：
- `busy` **必须**绑定真实的分析请求生命周期（请求发出→busy，响应回来→online）
- 头像区状态点 + 文字，点开可手动覆盖（手动优先，直到下次自动触发）
- **不要**在后端写"用户在线表"（那是 TASK-011 的活）

## 四、用户区（顶栏）

顶栏已是五件套（Logo + 数据源 + 提问框 + ☰菜单 + 用户区），本轮把**用户区**做实：
```
头像（名字首字）+ 状态点 + 名字 + 状态文字
点开 → 菜单：在线状态切换（四态）/ 个人设置（占位）/ 退出登录
```
- 名字来源：登录时填的姓名；游客则是「游客XXXXX」
- **退出登录** → 清本地会话 → 回登录页（状态置离线）
- 「个人设置」本轮只做占位（点开提示"暂未开通"），不要假装有功能

## 五、占位与诚实边界（重要）

- 右上「用户」面板/系统状态区里若出现"当前版本不校验登录身份"这类字样 →
  **改成人话**（例如「本地模式：身份仅用于展示与记录」），**不要**出现"鉴权/未启用/TASK-011"
- 「忘记密码」「立即注册」「个人设置」等未实现入口 → 点击给**明确的人话提示**（"该功能尚未开通"），
  **不要**做了按钮却点不动、也不要假装能用
