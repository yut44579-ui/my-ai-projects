# 施工指令 · B-UI 修订（登录表单改成「账号」形式 + 密码框改眼睛图标）

> 来源：用户原话「不要弄姓名这个 按照正常腾讯qq那种 账号形式的」+
>       「不要文字的 要一个眼睛的标志那种」（两张截图，同一批做、一次提交）
> 前置：STEP B-UI 已完成（`6f9a104` 归档）；本次只动 **UI 与文案**，不碰任何认证
> 铁律：`docs/前端展示规范.md`（前端只放业务内容，不出现技术字样）· `docs/防崩规范.md`

## 一、本次要改的对照表（改前 → 改后）

| 位置 | 改前 | 改后 |
|---|---|---|
| 字段标签 | 姓名 | **账号** |
| 输入提示 | 2~20 个字，填个你习惯的称呼 | **手机号 / 邮箱 / 用户名** |
| 输入上限 | `maxlength="20"` | `maxlength="40"` |
| 副标题 | 填个名字就能进，随时可以退出 | **登录后即可开始分析** |
| 勾选项 | 记住我（只记名字，不记密码） | **记住账号** |
| 主按钮 | 进入系统 | **登 录** |
| 底部链接 | 立即注册 | **注册账号**（与「忘记密码？」并列，均按诚实占位） |
| 游客文案 | 本机给你随机取个名字 | **不用填账号密码** … 游客**不留身份**，退出后名字会变 |
| 底部说明 | 名字只用于展示与记录 | **账号**只用于展示与记录 |
| 右上角身份 | 账号（名字由你自己填） | **账号（登录时你自己填的）** / 游客（本机随机取名，不留身份） |

## 二、校验（口径变了，形态校验的性质不变）

```
账号 2 ~ 40 个字符；密码 ≥ 6 位
仍然只做**形态**校验：不做哈希、不做比对、不发令牌、不建服务端会话（评审红线不变）
```

## 三、硬约束（不变）

- 只做 UI / 文案层调整，**不引入任何真实认证**（密码哈希 / Token / Session / RBAC 都不做）
- 前端不出现技术字样（不显示 `/api/`、`TASK-`、mime、哈希）
- 复用既有 TDesign token 与组件（`.field-label` / `.check` / `.link-btn` / `.login-foot` 原样用）
- 未开通的入口点了必须给人话提示（`该功能尚未开通：…`），**不许做成点不动的死按钮**
- 内部元素沿用旧 id / localStorage 键名（`login-name`、`sra.remembered-name`）：
  只改用户看得见的字，老用户「记住账号」的内容不丢
- **不引图标库**：图标一律内联 SVG（`stroke="currentColor"` + 圆角端点，16px 下描边 ~1.2px）
- 图标型按钮必须带 `title` + `aria-label`（同一个词），否则就成了看不懂的图标；
  纯动作按钮（登录 / 确认导入 / 分析 …）保持文字，不改成图标

## 四、密码框改成眼睛图标（用户原话「不要文字的 要一个眼睛的标志那种」，同一批做）

| 位置 | 改前 | 改后 |
|---|---|---|
| 密码框右侧 | 文字按钮「显示 / 隐藏」 | **眼睛图标**（内联 SVG，不引图标库） |
| 两态 | 文字替换 | **睁眼** = 明文藏着（标签「显示密码」）/ **闭眼加斜线** = 明文显示中（标签「隐藏密码」） |
| 无障碍 | 无 | `aria-label` + `title` 都是**当前动作**，另有 `aria-pressed`；SVG 自己 `aria-hidden` |
| 热区 | 文字大小 | **24×24**（不点不到） |
| 颜色 | `--text-2` | 默认 `--td-font-white-3` → hover `--td-brand-color` |
| 线条 | — | 与页面其它图标统一：16px 显示尺寸下描边都是 ~1.2px、圆角端点 |

**顺手扫出来的"图标型但写成文字"的按钮**（同一套图标规范）：

| 按钮 | 改前 | 改后 |
|---|---|---|
| `btn-reload-tasks` | 「刷新任务列表」 | 刷新图标 + `title`/`aria-label`「刷新任务列表」 |
| `btn-refresh-exec` | 「刷新」 | 刷新图标 + `title`/`aria-label`「刷新执行记录」 |
| `btn-doc-close` | 「收起」 | 收起图标（向上折角）+「收起正文」 |

**保持文字不动**（纯动作 / 导航，不该变成图标）：分析 / 登 录 / 开始分析 / 确认导入 / 上传 /
生成摘要 / 看完整回答 / 菜单项 / 标签页 / 登录页底部的文字链接（忘记密码？· 注册账号 · 帮助 · 隐私）。
顶栏的 ☰ 本来就是图标形（带 `title="菜单"`），本轮不动。
