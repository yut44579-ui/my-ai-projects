## D47 ★★ 装了文档解析库之后，行为**变对了**，不是变错了

**现象**：装了 python-docx / pypdf 之后，冒烟测试 2 从"5 篇入库"变成"3 篇入库"。

**原因**：
```
没装库时 → 代码返回「（未安装 pypdf，无法解析 xxx.pdf）」这种占位文字
        → 它**进了索引**（因为内容非空）
装了库后 → 假文件真的解析失败 → 内容为空 → **被如实跳过**
```

**★ 新的行为才是对的**：
往索引里塞一句"我读不了"毫无价值 —— 它会被检索到、稀释检索质量，
而且用户看到会以为系统在推卸责任。

**教训**：
> **"降级时的占位文字"不该进索引。**
> 降级是给人看的提示，不是知识。
> 这两者混在一起，会让检索结果里长期混着一堆噪音，而且很难查出来源。

## D48 ★★ 解析不了就跳过，但必须**说出来**

**决策**：`sync()` 返回 `skipped` 列表，每一条都带原因
（`note.docx（内容为空）`）。

**理由**：如果只是静默跳过，客户会觉得"我明明传了 20 个文件，怎么只接上 12 个"，
而且**完全无从查起**。

**★ 这是本项目第三次遇到同一个原则**：
```
不假装读过了（扫描件）
不假装抓到了（网页 404）
不假装接上了（API 契约不对）
→ 现在再加一条：**不假装全都接上了**（解析失败的要说出来）
```

## D49 ★★ 内网地址必须绕过代理

**现象**（测试发现的）：连一个必然失败的本机端口（`127.0.0.1:1`），
期望"连不上"，实际收到 **`HTTP 502`** —— 那是**代理返回的**。

**原因**：`httpx` 默认 `trust_env=True`，会读 `HTTP_PROXY` / `HTTPS_PROXY`。
于是**连内网地址也走代理**。

**★ 后果有两层，而且第二层更严重**：
```
① 功能上：内网服务连不上（代理转不过去），报一个假的 502
          → 排查时会以为是"接口写错了"，而不是"请求走错路了"
② 安全上：**内部接口的地址和参数被发到了外部代理**
          → 客户接内部 CRM 时，等于把内部地址告诉了第三方
```

**修法**：`connectors/http.py` 里判断目标是不是内网
（localhost / 127.x / ::1 / 10.x / 172.16-31.x / 192.168.x / `*.local` /
**没有点的主机名**），是内网就 `trust_env=False`。

**★ 最后那条"没有点的主机名"最容易漏**：
内网机器名通常没有域名后缀（`internal-crm`、`erp-server`），
只看 IP 段的话会漏掉它们。

## D50 ★★ 通用 API 连接器必须**定义契约**，而不是"支持 N 种系统"

**决策**：定义 5 个字段的最小契约：
```json
{"items": [{"id","title","content","updated_at","permission"}], "next": "游标"}
```

**理由**：
- 客户的内部系统千奇百怪，为每家写一个连接器 = 变成外包公司，规模不起来
- 契约只有 5 个字段，**客户 IT 半天就能对接完**，比"支持 20 种系统"实际得多

**★ 配套做的是 `probe()` 体检**，因为**"接不上"的原因必须说清楚**：
```
客户 IT 最常犯的错：返回 {"data": [...]} 而不是 {"items": [...]}

差的报错：  "解析失败"
好的报错：  "契约不对：期望顶层有 items 数组。
            实际顶层是 dict，键为 ['data']。
            如果你的数据在 data 字段下，请改成 items，或用 items_path 参数指定。"
```
第二种他五分钟就能改好。

## D51 网页连接器：不做爬虫，让客户明确给 URL

**决策**：`UrlConnector` 只抓你给的这几个 URL，**不自动发现站内链接**。

**理由**：
- 自动发现就变成爬虫了 —— 涉及 robots.txt、抓取频率、被抓站点的感受
- 而且很容易把整个官网（含招聘页、新闻页等无关内容）拉进来，
  **稀释检索质量**
- 让客户明确给几个 URL 更可控，也更符合"不要求他们改变现状"的定位

**实现**：用标准库 `HTMLParser`，不引 BeautifulSoup。
私有化部署的机器内存小，而且我们只需要"去掉标签留正文"。

**★ 一个容易漏的细节**：块级标签要**补换行**。
不补的话 `<p>第一段</p><p>第二段</p>` 会变成"第一段第二段"，
检索和阅读都会出问题。
