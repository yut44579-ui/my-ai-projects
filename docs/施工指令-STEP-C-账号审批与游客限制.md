# 施工指令 · STEP-C（账号审批 + 游客限制 + 文案简化）

> 归档说明：本文件按**用户 2026-09-25 那条指令的原话拆解**落盘。
> 上一轮（`docs/施工指令-注册功能.md`）把本地账号系统做完整了；
> 这一轮是在它上面补**审批**与**游客边界**。拆解与最终决定见 `docs/DECISIONS.md` **D21**。

## Scope（本轮做的四件事）

### ① 文案简化
登录页**删掉**那段长说明：「本地模式：账号与密码只保存在这台机器上；密码存成不可还原的校验值，
登录时用它核对，这里不保存密码原文。忘记密码没法用邮件找回（本机也没有邮件可发）。」
→ 改成**QQ 那种简洁形态**；需要解释的**移到「帮助」页**。**全站扫一遍同类长句。**

### ② 注册真入库
账号真持久化到本机（`state/accounts.json`），登录读它；**重启服务后账号仍在**（要能验证）。

### ③ ★ 管理员审批（用户替我们定的两个关键点）
- **第一个注册的账号自动成为管理员**（否则没人能批，死锁）
- **「系统设置」里加「账号管理」**（管理员登录后可见）：
  待审批列表（账号名 / 申请时间）+ 批准 / 拒绝；已批准列表（可停用 / 删除）
- 登录时**三种情况分清**：
  - 待审批 → 「账号正在等待管理员批准」（不是"账号或密码不对"）
  - 被拒绝 → 「该账号未通过审批」
  - 密码错 → 「账号或密码不对」
- **注册成功后不再直接进系统** → 提示「注册成功，等待管理员批准」（注意别留旧逻辑）

### ④ ★ 游客登录的限制 + 三角形警示
- **能用**：提问 / 看表格 / 看周报（只读浏览类）
- **不能用**：导入数据（换数据源）/ **导出报表** / 保存或修改任务 / 账号管理 / 删除操作
- **提示方式**：只在**受限处**显示 **⚠ 三角形警示符** —— 其它地方不显示（不许满屏）
- 游客点受限功能 → **弹窗**「**需要您先登录才能使用完整服务**」+「去登录」按钮
- 顶部一条**轻量**提示「游客模式 · 部分功能受限」，**不是**满屏遮罩

## Out of Scope（本轮明确不做，已记录）
- 管理员**授予**别人管理员身份（角色只在注册时定一次）
- 给业务端点（上传 / 导出 / 任务）加**服务端**权限校验 —— 它们是冻结契约，见 D21 的取舍说明
- 令牌 / 刷新令牌 / SSO / 多用户数据隔离（单机自用级别不变）
- 「个人设置」（仍是诚实占位）
