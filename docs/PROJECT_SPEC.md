## 项目目标（解决什么问题）

把"**每周手动做销售报表**"变成"**说一次，之后自动出**"。

现状痛点：从 Excel/数据库导数据 → 拉透视表 → 算指标 → 套格式，每周 1-2 小时，还容易算错且难以发现。

## 目标用户

单用户（本人）——需要定期出固定格式销售报表、但不会/不想写 SQL 的人。

## 核心场景

```
1. 建任务（一次）：上传已有报表样本（"照这个做"）或说大白话（"做个每周销售汇总"）
   → AI 出方案 → 用户确认 → 固化成任务
2. 自动执行：定时（如每周一 8:00）→ 取数 → 代码计算 → 渲染 Excel（保样式）→ AI 写解读
3. 异常可见：数据源变/字段缺失 → 明确报错，不产出错误报表
```

## MVP（第一版必须完成）

| # | 功能 |
|---|---|
| 1 | 数据源接入（Excel/CSV 上传 + MySQL 连接） |
| 2 | 数据字典（扫描字段，供 AI 映射） |
| 3 | 建任务（大白话 + 参考物 → AI 方案 → **人工确认** → 固化） |
| 4 | 数据映射（AI 列候选 → 用户选；找不到就提问） |
| 5 | 执行引擎（定时 + 手动 → 取数 → **代码算数** → 渲染 Excel） |
| 6 | 产出（Excel + AI 解读 → 页面查看/下载） |
| 7 | 执行记录（时间/状态/文件/错误，可追溯） |
| 8 | 失败处理（明确报错，不产出错误文档） |
