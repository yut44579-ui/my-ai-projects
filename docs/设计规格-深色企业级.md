# 设计规格 · 深色企业级销售分析平台（来自用户参考图）

> 来源：用户提供的 ChatGPT 生成参考图（2026-09-23）。**TASK-002 之后的 UI 一律以此为准。**

## 一、设计 Token（直接写进 CSS 变量）

```css
/* 背景三层明度阶梯（深色主题的核心） */
--bg-page:    #080B12;   /* 页面最外层 */
--bg-sidebar: #0A101C;   /* 侧边栏 */
--bg-card:    #0F1622;   /* 卡片（比底色亮 5~8%） */
--bg-inset:   #0A111C;   /* 卡片内嵌区（表格/输入框，比卡片更暗） */
--border:     #1E293B;   /* 统一 1px 描边（深色主题主要分隔手段，不用阴影） */

/* 主色（全局唯一强调色，只用于可点击/当前/关键数据） */
--primary:      #2563EB;
--primary-hi:   #3B82F6;
--primary-glow: rgba(37,99,235,.35);   /* 选中态外发光 */

/* 语义色（只承担数据语义） */
--success: #22C55E;   /* 上涨/增长 */
--danger:  #EF4444;   /* 下降/高优先级 */
--warning: #F59E0B;   /* 中优先级 */
--purple:  #8B5CF6;   /* 图标区分 */

/* 文字三级 */
--text-1: #E6EAF2;   /* 主：标题/关键数值 */
--text-2: #94A3B8;   /* 次：说明/表头/副标题 */
--text-3: #64748B;   /* 弱：时间戳/单位/占位符 */

/* 尺寸 */
--radius-card: 12px;  --radius-ctrl: 8px;  --radius-pill: 999px;
--gap: 16px;          --pad-card: 20px;
--h-topbar: 60px;     --w-sidebar: 200px;  --w-rightpanel: 355px;
```

**三条高级感的来源（必须锁死）**：
1. **三层明度阶梯**：#080B12（页）→ #0F1622（卡）→ #0A111C（卡内嵌）
2. **1px 描边替代阴影**：几乎全部卡片 `1px solid #1E293B`；阴影只用于主按钮和选中导航（配蓝色外发光）
3. **高密度小字 + 单点大数字**：正文/表头/说明全压在 **11~14px**，只有 KPI 数值是 **28~32px 粗体**

## 二、布局（1 顶栏 + 3 栏）

```
┌────────────────────────────────────────────────────────────────────┐
│ 顶栏 60px：Logo+「销售报表 Agent」+副标题 │ 全局搜索框(38%) │ 通知·帮助·设置·头像 │
├──────────┬─────────────────────────────────────┬───────────────────┤
│ 侧边栏    │ 主内容区（可滚动）                    │ 右侧面板 355px     │
│ 200px    │ 区块A AI 工作台（最大卡）             │ Tab: 权限/安全/熔断 │
│ 导航7项   │ 区块B KPI 行（4 数值卡 + 1 趋势折线图）│ 用户角色与权限      │
│ 底部卡    │ 区块C 三栏（核心结论·客户TOP5·产品排行）│ 访问控制(白/黑名单) │
│          │ 区块D 两栏（行动计划 2/3 · 生成周报 1/3）│ 安全策略(5开关)     │
│          │                                     │ 熔断机制·系统状态    │
└──────────┴─────────────────────────────────────┴───────────────────┘
```

**左侧导航**：首页 / 销售分析 / 客户分析 / 产品分析 / 周报中心 / 数据管理 / 系统设置
**侧栏底部**：🛡「权限与安全 已开启」+ 当前用户 / 角色 / 版本号

## 三、关键组件规格

| 组件 | 规格 |
|---|---|
| KPI 数值卡 | 图标 32×32（圆角 8，语义色底）+ 灰标题 + **28~32px 粗体数值** + 绿/红 ↑↓ 变化率 + 灰小字「较上周 XXX」 |
| 趋势折线图 | 双折线 + **渐变面积填充**（`rgba(59,130,246,.35)` → 透明）；本周亮蓝 2px，上周灰蓝弱化；稀疏刻度、无轴线、右上图例 |
| 排行榜表格 | **无外框**，仅靠行高/留白分隔；表头灰小字；排名用**蓝色圆形序号徽标**；状态用**胶囊标签**（红/绿/橙/蓝）；底部「查看全部 XX ＞」 |
| 进度条 | 细长圆角（5~6px），轨道 #1E293B，蓝色填充，右侧百分比对齐 |
| 卡片内边距 | 大卡 20px，KPI 卡 14~16px；卡片间距 16px |
| 表格行高 | 36~40px |
| 主按钮高 | 36~40px；小按钮/标签 26~30px |
| 图标 | 导航/权限 16~18px |

## 四、字体层级

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| H1 | 20~22px / 700 | 「你好！我是你的销售报表 Agent」 |
| H2 | 14~15px / 600 | 卡片标题 |
| **KPI** | **28~32px / 700** | 关键数值（货币符号小于数字） |
| 正文 | 13px / 400 | 结论条目、说明 |
| 表格 | 12~13px / 400~500 | 列表数值 |
| 表头/标签 | 12px / 500 | — |
| 辅助 | 11px / 400 | 时间戳、单位 |
| 侧栏导航 | 14px / 500 | — |

数字启用 `font-variant-numeric: tabular-nums` 保证表格对齐。

## 五、禁止（与文档第十九节一致）
大量空白 · 大量渐变 · 过度玻璃拟态 · 无意义动画 · **假数据** · **静态 Dashboard** · 为视觉增加无用模块 · 复杂配置挡住核心分析流程
