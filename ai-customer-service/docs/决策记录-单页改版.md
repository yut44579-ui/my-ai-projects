## D67 ★★★ 跳转报错的根因：`<a href>` 也需要子路径前缀

**现象**：从 `/demo/kefu/` 点「人工工作台」跳到 `/workbench.html` → 404。

**原因**（D59 的漏网之鱼）：
```
D59 我只修了 fetch('/api/...')，**没修 <a href="/...">**
→ 页面里的超链接同样会被解析成网站根路径
```

**★ 教训**：
> **子路径部署影响的不只是接口请求，还有所有绝对路径** ——
> 超链接、图片 src、CSS 里的 url()、表单 action，全都要处理。
> 我当时只想到"接口会 404"，没想到"链接也会"。

**修法**（也是用户想要的）：**直接合并成一个页面**，标签页切换。
没有了页面跳转，这类问题从根上消失。

```
试一句 │ 知识库 │ 模型 │ 学习 │ 治理 │ 人工
```

★ 顺带的好处：**改一处配置不用来回跳**，比原来三个页面顺手得多。
用户说"分开三个页面很繁琐"，是对的。

## D68 ★★ 模型必须能在界面上配

**用户原话**：「控制台模型也弄不了」。

**原来**：模型只能读 `.env`，改一次要重启服务。
对一个要交给客户用的产品，这是不可接受的 ——
客户可能先用我们的 key 试，之后换成自己的；也可能从 DeepSeek 换到别家。

**修法**：新增 `app/settings.py`，优先级 **数据库 > 环境变量 > 默认值**。

**★★ 两条关键设计**：

**① 密钥只回显遮罩，完整 key 永不回传**
```
显示：sk-eee********e92d
```
否则"在界面上看一眼 key"就等于泄露一次。

**② 但遮罩串提交回来时，必须识别成"不改"**
```
界面上显示的是 sk-eee********e92d
用户没动它 → 原样提交 → 如果当成新 key 存进去，**服务立刻就不能用了**
→ 规则：带 `*` 的一律视为不改
```
**实测确认**：提交遮罩串后 `changed: []`，且 key 仍然能调通。

**③ 必须能"真调一次"测**
只检查"字段填了没有"发现不了 key 错、地址错、模型名错。
实测：`{'ok': True, 'model': 'deepseek-chat', 'reply': '正常', 'tokens': 16}`

## D69 ★★ 知识库导入要"能看见、能拖、能粘"

**用户原话**：「知识库也不知道怎么导入」。

**修法**：知识库页给四种入口，覆盖客户手里资料的所有形态：

```
① 拖文件上传      Word / Excel / PDF / 纯文本，一次多个
② 粘贴一段文字    手里有制度，直接复制进来，不用先存文件
③ 目录路径        共享盘、导出目录（★ 会同步删除）
④ 网页 / 内部接口  官网、公众号、CRM
```

**★ 配套的两件事**：
- **导入后的清单**（我的资料进去了没有、几块、能不能对客户说）
- **接入前扫描**（找出"标着可对客户说但内容里有敏感东西"的资料）

**关键取舍**：解析失败的文件**如实列出原因并跳过**，
不塞一句"我读不了"进索引（D47 的教训）。

## D70 ★★ 模拟官网：从"文本说明"改成"真的一个官网"

**用户原话**：「不要一些文本描述，你就去网上找 模拟一下嘛」。

**原来**：一个白底页面，上面写着"这是模拟一个客户官网，右下角那个圆按钮就是客服挂件"。
**那是个说明书，不是官网** —— 没法让人感受到"挂在真站点上是什么样"。

**改成**：一个完整可信的 B2B 制造企业官网
```
恒信精工 · 精密零部件制造
  顶部信息条（电话/工时/EN）
  吸顶导航（产品/能力/资质/关于/联系）
  Hero（深色 + 网格底纹 + 4 个数字 + 车间实时概览卡）
  为什么选我们（4 个数据卡）
  三条产品线（带图标和要点）
  制造能力
  资质认证条
  客户评价（3 条，带头像和身份）
  联系表单（深色区）
  页脚
  + 右下角客服挂件
```

**★ 关键细节**：Hero 右侧不是放张图（我造不出图），
而是做成**「车间实时概览」** —— 进度条 + 百分比。
这比放一张莫名其妙的产品图更像真站点，而且**纯 HTML 就能做**。

**★★ 而且演示资料要跟官网对得上**：
```
官网写「打样周期 7 天」→ 知识库里就得有《交期与起订量》
官网写「±0.005mm」     → 知识库里就得有《公司简介》
官网写「IATF 16949」   → 知识库里就得有《资质认证》
```
第一版没对上，问「打样要多久」直接转人工 —— **演示效果大打折扣**，
因为访客会觉得"这 AI 连官网上写的都不知道"。

补了 10 份资料（含 Word 和 Excel 各一份，演示真实文档解析；
2 份标为仅内部，演示权限隔离）。

**修复后实测**（走公网）：
```
打样要多久      → 常规件 7 天，复杂件 10 到 15 天。出处《交期与起订量》
精度能做到多少  → ±0.005mm，半导体件 ±0.002mm。出处《公司简介》
有哪些资质认证  → IATF 16949、ISO 9001…出处《资质认证》
最小起订量多少  → 打样 1 件起做…出处《交期与起订量》
不良率超标怎么办 → 超过 2% 全批退回重做。出处《售后服务承诺》（★ Word 表格里的）
能报个价吗      → 转人工（报价类，代码层拦）
内部员工问报价底线 → 最低 8 折
外部客户问同一句   → 这个我答不了（★ 权限隔离生效）
```

## D71 ★★ 检查器不能写死文件列表

**现象**：我加了 `site.html`，但 JS 语法检查器**没检查它** ——
因为里面写死了 `['index.html','workbench.html','widget.html']`。

**★ 这类问题很隐蔽**：检查器**不报错，只是安静地不检查**。
比"检查失败"危险得多 —— 你会以为它覆盖了。

**修法**：改成自动发现 `web/*.html`。

**同一类问题在 D64 也出现过**（护栏举报自己），
在 D61 也出现过（手机适配只有量窄屏才能发现）。
**共同的教训：「覆盖范围」本身也要验证，不能假想。**

## D72 出处显示的两个坑

**坑①**：`<a href>` 没加前缀（见 D67）。
**坑②**：答案里已经写了「〔出处：…〕」，下面又显示一行**不同的**出处。

```
原因：命中了 2 篇资料，AI 在正文引了《交期与起订量》
      我的显示逻辑是"把已出现在正文里的过滤掉，剩下的显示"
      → 过滤掉《交期与起订量》，剩《公司简介》被显示出来
      → 看起来像"AI 引用错了资料"，实际只是显示逻辑的问题
```
**修法**：正文里已经带出处了，就**不再显示额外那行**。
