# ★ 刻意**不引入**的东西，以及原因：
#
# · sentence-transformers / torch
#   语义检索要它，但装上就是 2GB+ 依赖，而且中小企业私有化部署的机器
#   往往只有 2GB 内存（你自己那台腾讯云就是 2G，跑起来只剩 600MB）。
#   所以里程碑 1 先用 2-gram + BM25 跑通，语义检索做成**可插拔**：
#   有 GPU/内存就接远端 embedding API，没有就退化成纯关键词。
#
# · 向量数据库（faiss/milvus/chroma）
#   同理。中小企业量级（几千到几万块）用 SQLite 全表扫 + BM25 完全够，
#   上了向量库反而多一个运维负担。等量级真上来了再换。
#
# · 任何状态管理/任务队列（celery/redis）
#   客服量级不需要。★ 但要注意：降级/熔断的"档位状态"如果存在进程内，
#   将来多实例部署会失效（A 机器降级了 B 机器还在打主模型）。
#   所以档位状态**落库**，不落进程内存。
